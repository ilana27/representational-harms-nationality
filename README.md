## HuggingFace Datasets

All narrative data is hosted on HuggingFace and loaded automatically by the notebooks.

| Dataset | Description | Used by |
|---|---|---|
| [`ilana27/llm-nationality-bias-us-narratives`](https://huggingface.co/datasets/ilana27/llm-nationality-bias-us-narratives) | 500K LLM-generated narratives (GPT-3.5, GPT-4, Llama 2, Claude 2, PaLM 2) with nationality labels from the QA model. Each HF split corresponds to one model. | `00`, `01` |
| [`ilana27/llm-nationality-bias-global-narratives`](https://huggingface.co/datasets/ilana27/llm-nationality-bias-global-narratives) | 292,500 narratives generated by GPT-4.1-Nano across 195 globally recognized nations. Each split corresponds to a prompt domain/condition. | `02` |

### Accessing the datasets manually

```python
from datasets import load_dataset

# Study 1 — all model splits
dataset = load_dataset("ilana27/llm-nationality-bias-us-narratives")
df = dataset["ChatGPT4"].to_pandas()   # one split per model

# Study 2 — global narratives
dataset = load_dataset("ilana27/llm-nationality-bias-global-narratives")

```

To browse or download the datasets directly, visit the dataset pages linked in the table above.

## Running the Notebooks

Run the notebooks in order. Each notebook depends on the one before it.

### 00 — Fine-tune QA Model

**`00_Finetune_QA_Model.ipynb`**

Fine-tunes a GPT-4.1-Mini model to extract nationality references (country names and demonyms) from LLM-generated narratives. Also runs inference on the Study 1 dataset and uploads the labeled results to HuggingFace.

**Prerequisites:** OpenAI API key.

**Steps:**
1. Set your OpenAI API key in cell 3.
2. Run all cells in order.
3. The fine-tuning job is asynchronous — monitor progress in cell 13 until the job status shows `succeeded`.
4. Once complete, the fine-tuned model ID is printed. Save it for reference.
5. Inference results are saved to HuggingFace under the `nationality_labeled` split of `ilana27/llm-nationality-bias-us-narratives`.

**You can skip this notebook** if you only want to reproduce the analysis — the labeled data is already available on HuggingFace.

---

### 01 — Study 1: US-Centric Narratives

**`01_Study1_US_Narratives.ipynb`**

Analyzes nationality bias in the 500K US-centric narratives (Shieh et al., 2024). Reproduces all Study 1 figures and tables from the paper.

**Prerequisites:** None beyond HuggingFace access. Auxiliary name data (see Setup above) required for race/name analysis cells (steps 1–4).

**Steps:**
1. Run cell 3 (HuggingFace loading) — loads all model DataFrames and the nationality-labeled dataset.
2. Run cell 18 (Pre-Req) to process and cache the Sood and Le auxiliary name datasets locally as CSV. Only needed once.
3. Run remaining cells in order. Each `#@title` cell is a self-contained analysis step.

**Key outputs** (saved to `Analysis/` directory):
- `Analysis/500K_Race_First_Name_Matched_sood_le.csv` — name-race matched data
- `Analysis/500K_Race_Name_Likelihoods_*.csv` — race likelihood tables
- `Analysis/500K_Table_2_Omission_Univariate.csv` — Table 2 (omission by domain)
- `Analysis/Rerun_500K_Table_3_Subordination_Intersectional.csv` — Table 3 (subordination)
- `Figure1_Dom_Sub_Choropleth.png` — Figure 1 choropleth map
- `Figure0_G77_Countries.png` — G77 member countries map

---

### 02 — Study 2: Global Narratives

**`02_Study2_Global_Narratives.ipynb`**

Analyzes nationality representation in the 292.5K global narratives across 195 countries. Includes n-gram frequency analysis and TF-IDF analysis comparing Global Majority vs. Global Minority narratives.

**Prerequisites:** None beyond HuggingFace access. Does not require Study 1 outputs.

**Steps:**
1. Run all cells in order.
2. Step 6 (n-gram) partitions the data into Global Majority and Global Minority subsets and saves them as `Global_Majority.csv` and `Global_Minority.csv`.
3. Step 6b (TF-IDF) reads those CSV files — run after step 6.

**Key outputs:**
- `Global_Majority.csv`, `Global_Minority.csv` — partitioned narrative datasets
- `global_majority_unigrams.csv`, `global_minority_unigrams.csv` — n-gram frequency tables
- `Global_Majority_unigrams.csv`, `Global_Minority_unigrams.csv` — TF-IDF scored terms
